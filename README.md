## 🚀 快速开始
### 本地运行
1. 下载项目
2. 用浏览器打开 `index.html`

### 在线编辑
1. 访问 GitHub 仓库
2. 点击文件旁的编辑图标修改

## 🔧 自定义内容
编辑 `index.html` 文件：
1. **个人信息**（姓名、联系方式）
2. **教育背景**（学校、专业）
3. **项目经历**（项目描述、技术栈）
4. **技能列表**（技能名称、掌握程度）

## 📱 响应式设计
- **手机端**：单列布局，汉堡菜单
- **平板端**：两列布局
- **桌面端**：完整布局
